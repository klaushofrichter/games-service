# Quartet

Pass a token around the table until it has gone round the set number of times.

Quartet is a **test game** for the platform. It checks turn order and games that need an exact number of players. There is no winner.

## In short

- When you hold the token, tap **Pass the token**.
- Four players pass it around the table for the set number of laps. There is no winner: it is a test game.

## What you see

- **The board** shows how many passes have been made, for example `3/8`, and who holds the token. That player's seat is highlighted.
- **Your phone** shows the pass count and one button.

## How a turn works

1. When you hold the token, your phone buzzes and the button says **Pass the token**.
2. Tap it. The token goes to the next player in seat order.
3. Everyone else sees **Wait for your turn**.

## Players

- Exactly 4 players, all people. AI players cannot play Quartet.
- If anyone leaves, the game ends.
- There is no time limit.

## Settings

| Setting | Default | What it does |
|---|---|---|
| Laps | 2 | Times the token goes round the table (1–5) |

## End of the game

The game ends when the token has been passed laps × 4 times, so 8 passes with the default setting.
