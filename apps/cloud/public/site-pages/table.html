Build the table

A touchscreen, set into a table.

The Game Table we play on: a wooden table with a touchscreen set flat into its top, a small computer underneath that runs Game Table, a power outlet and a volume knob in the side, and the players' phones as their hands. This page shows how it is built: the photos, the parts, the tools and the steps.

Step by step Draft

The steps in outline. Measurements, photos of each step and what we learned on the way are still to come.

  1. Choose the screen, then plan around it

    Measure the screen's front, its depth, and where its cables and buttons are. Decide where it sits in the top, how far its front stands above the wood (flush is nicest), and where the computer, the outlet and the knob go.

  2. Make the table narrower

    The table comes square, with its top in two halves; we used one. Cut two of its rails to the new length, and drill the fresh ends with the Forstner bit, so that the legs have something to attach to again.

  3. Mark the opening

    The opening is stepped: on the top, a pocket the size of the screen, a little larger so that it drops in; from below, a smaller opening, 1 inch inside it all around, which leaves a 1-inch ledge for the screen to sit on. Tape the top, draw both, check the corners with the square, and measure again.

  4. Cut the opening

    Rout the pocket from the top along a clamped straight edge, down to 1/8 inch above the underside: that thin rim is surprisingly stable. Then cut the smaller opening through from below, and finish the corners with the oscillating tool. The top's pressed-fibre core routs easily, and the oscillating tool is good for fine-tuning the fit. File and sand the edges.

  5. Fit the supports

    Take the monitor's stand and back cover off: the screen stays cooler without it, and lies flatter. Lay it on the ledge, with rubber strips where its frame is narrower so that it lies level with the top, and screw two wooden bars across its back to the frame underneath, with strips on them too, so that the bars take its weight and the thin ledge doesn't carry it alone. Leave room for its cables.

  6. Frame the opening

    Saw the aluminium trim to length, then file each end by hand to a 45-degree angle until the corners meet. Glue it around the opening with hot glue. The frame is wide enough to hide any unevenness in the cut, and it gives the screen a clean border.

  7. Outlet and volume knob

    For the power outlet, drill a pilot hole through the table's side, then rout the opening from the outside to fit the outlet. For the volume knob, rout a pocket from the inside that fits the unit, and drill a small hole through for its LED and the shaft of its knob. Fit the unit from the inside, then put the knob on its shaft from the outside: it comes off.

  8. The computer and the cables

    Fix the small computer under the top, connect the screen (video and touch), the knob and the power, and clip the cables along the frame, away from knees and feet.

  9. Put the screen in and test

    Lay the screen in, start the computer, and check that a touch lands where the finger is, in every corner.

The software

Install Game Table on the table's computer with the package for its system (Download). The installation guide for Linux shows how to make it a table of its own, step by step. Players join with their phones by scanning the code on the board.

What runs on our table's computer:

WhatHow we set it up
Operating systemDebian 13 ("trixie") with the XFCE desktop and the LightDM login manager. The touchscreen works out of the box, without calibration.
Logs in by itselfLightDM logs the table's user in at start-up, and the computer's BIOS is set to switch it on again after a power cut: the table comes back on its own.
Never locks or sleepsThe screen lock (light-locker) is off, screen blanking and power saving are off (xset s off -dpms at login, and XFCE's power manager in presentation mode).
One tap to startDesktop icons open with a single tap, since a double tap on a touchscreen is not always caught. The Game Table icon starts game-table --kiosk --repos all --pointer off: the board full screen in Chrome, without a mouse pointer. Quit the table on the board, or closing the browser, ends it.
BrowserGoogle Chrome from Google's own package source, not Debian's Chromium: kiosk mode, and the USB devices some games use, need it.
On-screen keyboardonboard, started at login; it comes up by itself when a text field is touched. A desktop icon opens it by hand.
Private gamesA GitHub token that can only read the private game repositories, kept in a file only the start script reads. (With automatic login the desktop's keyring stays locked, so GitHub's own sign-in would stop the start.)
SoundThrough the USB soundbar inside the table. The volume knob in the table's side works as soon as it is plugged in, like a keyboard's volume keys; nothing to set up.
NetworkA network cable; Wi-Fi works too. The phones need the same network as the table.
Looking after itSecurity updates install themselves (unattended-upgrades), and SSH lets us look after the table from another computer.

Bluetooth keyboards: an old one (from 2011) paired but would not stay connected. A keyboard with a USB receiver, or a newer Bluetooth one, works.
