Access codes

A code approves a table at once, with no pairing code: start the table with TABLE_CODE=ABCD-EFGH (or --code ABCD-EFGH), or type the code in its board's settings. A code serves one table: the first one that uses it keeps it, others are refused until you release it. The validity only matters for that first use; a table already connected keeps working and is flagged here once its code has run out. Revoking or deleting a code disconnects its table.

Game repositories

Extra games from other GitHub repositories, each with a games/ folder like games-service's. A table gets a repository's games when it is ticked on the table's row, when approving it, or from its access code. Repositories marked deploy config come from deploy/game-repos.json and can only be changed there; ones added here are kept by the service like its tables.

Game logs

Every game's log, uploaded by its table when the game ends (also simulations, and games a table stopped in the middle of). Each zip has a README describing its format, for reading it yourself or with Claude.
